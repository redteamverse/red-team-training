What Your Team Will Learn

Active Directory often forms the backbone of complete enterprise networks and plays a central role in managing enterprise environments. Securing Active Directory requires understanding the techniques and attack methods used by adversaries to compromise enterprise environments.

Understanding how attacks work requires a focus on methodology and techniques, not just the tools used to execute them. Through hands-on AD training, attendees build the knowledge needed to assess, attack, monitor, and defend Active Directory environments.

Enumerate Active Directory and Identify Attack Paths

Learn how to enumerate Active Directory environments, map trust relationships, and identify privileges to detect potential attack paths.

Perform Privilege Escalation and Credential Replay Attacks

Learn how to escalate privileges and move across Active Directory environments through local and domain privilege escalation techniques and lateral movement.

Execute Lateral Movement, Trust Abuse, and Persistence

Learn how to abuse trust relationships, execute cross-forest attacks, and maintain access through persistence techniques.

Monitor, Defend, and Bypass Active Directory Defenses

Learn how to monitor Active Directory environments, understand defensive controls, and explore techniques used to bypass common security defenses.

Course Modules

Course Content

This training is structured into four practical modules covering Active Directory enumeration, trust and privileges mapping, privilege escalation, credential replay attacks, Kerberos attacks, cross-forest trust abuse, persistence, monitoring, defenses, and bypassing defenses.

  • Enumerate useful information such as users, groups, group memberships, computers, user properties, trusts, and ACLs to map potential attack paths.
  • Learn and practice different local privilege escalation techniques on a Windows machine.
  • Hunt for local administrator privileges on machines in the target domain using multiple methods.
  • Abuse enterprise applications to execute complex attack paths involving antivirus bypass and pivoting to different machines.
  • Learn how PowerShell tools can still be used for Active Directory enumeration.
  • Learn to modify existing tools to bypass Windows Defender.
  • Bypass PowerShell security controls and enhanced logging, including System-Wide Transcription, Antimalware Scan Interface (AMSI), Script Block Logging, and Constrained Language Mode (CLM).
  • Learn how to modify and use .NET tools to bypass Windows Defender and Microsoft Defender for Endpoint (MDE).
  • Learn to use .NET loaders that can run assemblies in memory.
  • Find credentials and sessions belonging to highly privileged domain accounts, such as Domain Administrators, extract their credentials, and use credential replay attacks to escalate privileges while using built-in protocols for pivoting.
  • Extract credentials from restricted environments where application allowlisting is enforced, abuse derivative local administrator privileges, and pivot to other machines to escalate privileges to the domain level.
  • Understand the classic Kerberoasting attack and its variants for privilege escalation.
  • Understand and exploit Active Directory delegation issues.
  • Learn how to abuse privileges associated with Protected Groups to escalate privileges.
  • Abuse Kerberos to persist with Domain Administrator privileges and forge Golden, Diamond, and Silver tickets.
  • Subvert authentication at the domain level using Skeleton Key and custom Security Support Providers.
  • Abuse the Directory Services Restore Mode administrator account for persistence.
  • Abuse protection mechanisms such as AdminSDHolder for persistence.
  • Abuse the minimum rights required for attacks such as DCSync by modifying ACLs on domain objects.
  • Modify the host security descriptors of a domain controller to maintain persistence and execute commands without requiring Domain Administrator privileges.
  • Elevate privileges from Domain Administrator in a child domain to Enterprise Administrator in the forest root by abusing trust keys and the KRBTGT account.
  • Execute intra-forest trust attacks to access resources across the forest.
  • Abuse database links to achieve code execution across the forest using databases.
  • Learn about Active Directory Certificate Services and execute some of the most widely used AD CS attacks.
  • Execute attacks across domain trusts to escalate privileges to Enterprise Administrator.
  • Learn about useful security events logged when the attacks discussed during the training are executed.
  • Explore architecture changes that can help organizations mitigate the discussed attacks, including temporary group membership, ACL auditing, LAPS, SID filtering, selective authentication, Credential Guard, Windows Defender Application Control, Protected Users, Privileged Access Workstations, tiered administration, and ESAE or Red Forest.
  • Learn how Microsoft Advanced Threat Analytics and similar security tools detect domain attacks and explore techniques used to avoid or bypass those detections.
  • Understand how deception can be effectively deployed as an Active Directory defense mechanism.
  • Learn about Microsoft Defender for Endpoint and understand the telemetry and components MDE uses for detection.
  • Execute an entire chain of attacks across a forest trust without triggering alerts from Microsoft Defender for Endpoint.
  • Use the Microsoft security dashboard to verify MDE bypass techniques.
  • Learn about Microsoft Defender for Identity and understand how MDI uses anomalous behavior to identify attacks.
  • Bypass various Microsoft Defender for Identity detections throughout the course.
