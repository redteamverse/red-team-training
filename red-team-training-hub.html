Training Categories

Red Team Training Across Enterprise Environments

01 Active Directory

Active Directory Training for Red & Blue Teams

Learn how attackers move through Active Directory environments, from domain enumeration and privilege escalation to Kerberos attacks and trust abuse. Practice these techniques in hands-on labs and learn how to monitor Active Directory activity and strengthen its defenses.

02 Azure Cloud

Azure Cloud Training for Red & Blue Teams

Learn to attack and defend Azure and Entra ID in live cloud labs. Discover exposed services, gain access, escalate privileges and move across tenants or between cloud and on-premises environments.

03 Enterprise AI

Enterprise AI Red Teaming

Learn to attack and defend Copilot, Copilot Studio, Microsoft Foundry and AI agents across Microsoft 365 and Azure. Explore prompt injection, agent identity abuse, privilege escalation and guardrail bypasses in live labs.

Explore Red Team Training Programs

Foundation Active Directory

Active Directory Attacks for Red and Blue Teams - Basic Edition

This training takes you through attacking and defending a modern Active Directory environment, starting from a compromised user desktop. You will use PowerShell and other trusted Windows resources to enumerate the domain, map privileges and trusts, and work through local and domain privilege escalation, Kerberos attacks, credential replay, persistence and cross-forest trust abuse.

View Training →
Advanced Active Directory

Active Directory Attacks for Red and Blue Teams - Advanced Edition

This training takes you through Red Team operations in a patched, multi-forest Active Directory environment. Starting with a standard domain account, you will map privileges and trust relationships, then work through local and domain privilege escalation, lateral movement, persistence and attacks across forest trusts.

View Training →
Advanced Windows

Advanced Windows Tradecraft

This training takes you through a tradecraft for Red Teaming a Windows environment with nothing but trusted OS resources and languages. We will cover multiple phases of a Red Team operation like initial foothold, enumeration, privilege escalation, persistence, lateral movement, exfiltration etc. in a fully updated and patched lab with countermeasures enabled.

View Training →
Beginner Azure Cloud

Cloud Attacks for Red and Blue Teams in Azure - Beginner’s Edition

This hands-on training aims towards abusing Azure AD and a number of services offered by it. We will cover multiple complex attack lifecycles against a lab containing multiple live Azure tenants.

Beginner Enterprise AI

AI Red Team Tactics for M365, Copilot and Enterprise AI

This training introduces AI Red Teaming across Microsoft 365 and Azure. Learn to attack and defend Copilot, Copilot Studio and Microsoft Foundry, then practice attacks against agent identities in Entra ID, identity boundaries and AI guardrails through live labs and real-world scenarios.
